DATE INVITATION WEBSITE
=======================

Files:
- index.html: invitation page with Yes / moving No buttons
- date.html: date details form, which prepares a WhatsApp message
- style.css: shared responsive styling

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Press Yes to reach the details page.
4. Fill in date/time, location, and food, then press Send to WhatsApp.

WhatsApp:
The number is configured as 249126013364 (international format, without the leading domestic 0).
If that is not the correct WhatsApp number, edit `whatsappNumber` in date.html.

Notes:
- The WhatsApp button opens a pre-filled message. The visitor still presses Send inside WhatsApp.
- Google Fonts are loaded online; the site still works without them using system fonts.
- For public hosting, upload all three files to the same folder on a static host such as GitHub Pages or Netlify.
